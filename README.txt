A S Vinay Kumar - Portfolio (static website, no install needed)

RUN ON YOUR COMPUTER
Double-click index.html. It opens in your browser.

GET ONE PUBLIC LINK FOR HIRERS (free, about 2 minutes)
Option 1 - Netlify Drop: go to app.netlify.com/drop and drag this whole folder onto the page. You get a link like https://your-name.netlify.app (you can rename it in site settings).
Option 2 - GitHub Pages: create a repo, upload index.html, then Settings > Pages > deploy from the main branch. Link: https://YOUR-USERNAME.github.io/REPO-NAME
Option 3 - Vercel: import the folder at vercel.com/new.

EDIT CONTENT
Open index.html in any text editor (VS Code, Notepad) and change the text. Save and refresh the browser.
